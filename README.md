# Login Ionic 📱

Aplicação mobile desenvolvida com **Ionic Framework**, **Angular** e **TypeScript** focada na implementação de telas e fluxos de autenticação (Login e Cadastro). 

O projeto foi construído como parte da formação técnica em **Informática para Internet**, com o objetivo de explorar os conceitos fundamentais do desenvolvimento mobile híbrido e a estruturação de interfaces responsivas e funcionais.

---

## 🚀 Tecnologias Utilizadas

- **[Ionic Framework](https://ionicframework.com/):** Construção de componentes e interface para aplicações mobile.
- **[Angular](https://angular.io/):** Estrutura de navegação, bindings e gerenciamento de estado da aplicação.
- **[TypeScript](https://www.typescriptlang.org/):** Tipagem estática e lógica orientada a objetos no frontend.
- **[Node.js](https://nodejs.org/) / npm:** Gerenciamento de dependências e ambiente de execução.
- **HTML5 & SCSS:** Estilização e estruturação dos componentes.

---

## 📌 Funcionalidades Principais

- 🔐 **Tela de Login:** Interface com validação básica de campos para acesso do usuário.
- 📝 **Tela de Cadastro:** Formulário para inclusão de novos usuários na plataforma.
- 🎨 **Componentes Híbridos:** Utilização de elementos nativos do Ionic para uma experiência fluida no dispositivo.
- 🧭 **Navegação por Rotas:** Fluxo contínuo entre as telas da aplicação.
